# Feliz Cumpleaños

Esta es una página estática para compartir como regalo digital.

## Cómo publicarla

1. Sube esta carpeta a un repositorio de GitHub.
2. En Settings > Pages, selecciona la rama principal y la carpeta raíz.
3. GitHub te dará una URL pública.

También puedes subirla a Netlify o Vercel arrastrando la carpeta.
